# Reflect on a Stalled Cycle

Step back from the current trajectory. This is a temporary reassessment prompted by several Cycle rounds without tool activity, not a workflow phase and not a request for a formal reflection report.

Re-read the recent session and reconsider what is preventing useful action. Challenge stale assumptions, unsupported conclusions, repeated explanations, unclear goals, external dependencies, and work that may have been declared complete without proportionate evidence. Look for an overlooked high-value action inside the established scope, including an incomplete user-visible path or a relevant difference between sibling clients when the task concerns product completeness.

Then act naturally:

- If the reassessment reveals a concrete, worthwhile, authorized action, begin it in this round and verify it proportionately.
- If useful work depends on external input or new authorization, state the precise waiting condition and ask only when the user can actually unblock it.
- If no candidate has enough value, certainty, authorization, or benefit relative to cost, say so briefly and end the round.

Do not manufacture tasks, repeat already sufficient checks without a new hypothesis, create Cycle bookkeeping, or emit a special marker. Reflection changes perspective; it does not impose a Do/Check/Reflect/Plan sequence.
